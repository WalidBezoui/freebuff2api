# Proxy Auth & Diagnostic Invariants

1. **401 Unauthorized Diagnosis (Local Proxy vs. Upstream)**:
   - When a client receives `401 Unauthorized: Invalid API key — ensure client sends Authorization: Bearer <FREEBUFF_API_KEY>...`, the error is strictly generated by `worker.js` auth gate on Vercel.
   - Codebuff never receives rejected 401 requests. A 401 error is an authentication mismatch between client and proxy, **never** an upstream account ban or detection.

2. **Codex CLI Configuration (`~/.codex/config.toml`)**:
   - Provider `[model_providers.freebuff]` must define `env_key = "FREEBUFF_API_KEY"`.
   - The shell environment or launcher script must provide `FREEBUFF_API_KEY`.

3. **Batch Launcher Invariant**:
   - All `.bat` launcher files must contain:
     `if "%FREEBUFF_API_KEY%"=="" set FREEBUFF_API_KEY=freebuff-default-key`

4. **Testing Protocol**:
   - Always run `npm test` for development verification (200+ tests, 0 upstream quota used).
